# Curso de Robot Framework 🤖

Este repositório contém exercícios desenvolvidos durante meu estudo de **Robot Framework**, uma ferramenta de automação de testes baseada em Python.

---

## 📌 Sobre o projeto

O objetivo deste repositório é praticar e consolidar os principais conceitos da automação de testes com Robot Framework, incluindo:

- Criação de casos de teste
- Uso e manipulação de variáveis
- Escopos de variáveis (local, teste e global)
- Criação de keywords personalizadas
- Estruturação básica de testes automatizados
- Geração de logs e relatórios de execução

---

## 🧪 Conteúdo

O projeto contém exemplos e exercícios práticos organizados em arquivos `.robot`, utilizados para aprendizado progressivo da ferramenta.

---

## 🎯 Objetivo

Este repositório tem fins educacionais e serve como base para desenvolvimento de habilidades em automação de testes com Robot Framework.
